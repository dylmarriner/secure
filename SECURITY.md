# Security Policy

## Current status

Secure is pre-release security software. Do not rely on the repository for high-risk communication until the relevant release has completed independent security review.

## Reporting vulnerabilities

Do not publish exploitable security issues, key material or sensitive reproduction data in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available to you.

## Security claims

The project will not claim to be untraceable, forensically invisible, guaranteed anonymous or capable of guaranteed remote deletion. Security claims must be scoped to implemented and tested properties.
